# Install FocusMute / 安装 FocusMute

Requires desktop Google Chrome 120+. No compilation, Node.js or Python is needed.

1. Extract the ZIP and keep the extracted folder in a permanent location.
2. Open `chrome://extensions` and turn on Developer mode.
3. Click Load unpacked and select the folder containing `manifest.json`.
   - Packaged release ZIP: the extracted folder itself.
   - GitHub source ZIP or clone: the `extension` subfolder.
4. Reload already-open YouTube and Xiaohongshu tabs.
5. Pin FocusMute to access Pause / Resume and Settings.

需要桌面版 Chrome 120 或更新版本。

1. 解压并保留文件夹。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择含有 `manifest.json` 的目录。Release 安装包选择解压目录本身；仓库源码选择其中的 `extension` 子目录。
4. 刷新已经打开的 YouTube 和小红书标签页。
5. 固定插件图标，方便暂停、恢复和设置。

If replacing an older personal extension, pause or disable that copy first. When updating, replace files at the same path, reload the extension, then reload affected site tabs. Do not run two FocusMute copies at once.

Project and full documentation: https://github.com/jkkjjj/focus-mute
